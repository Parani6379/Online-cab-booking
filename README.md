# Online Cab Booking System

This project is a web-based Online Cab Booking System developed to simplify the process of booking taxis through an online platform. The system allows users to search for available cabs, book rides, and manage their bookings, while administrators can manage drivers, vehicles, and ride details.

## Features

### User Features
- User registration and login
- Search available cabs
- Book a cab ride
- View booking history
- Cancel bookings

### Admin Features
- Manage drivers
- Manage cab details
- View and manage bookings
- Monitor system activity

## Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Development Tool: XAMPP / Local Server

## Project Purpose

The main goal of this project is to demonstrate how an online transportation booking system works and to provide a simple implementation of ride booking management using web technologies.
